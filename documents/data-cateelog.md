# 📖 Data Catalog: Gold Layer (Data Mart)

## 📌 Overview
The **Gold Layer Data Mart** represents the curated, business-ready star schema designed for reporting, analytics, and business intelligence (BI). It consolidates cleaned data from upstream layers into a dimensional model consisting of one central fact table and two primary dimension tables.

---

## 📐 Schema Architecture
* **Schema Name:** `gold`
* **Model Pattern:** Star Schema
* **Fact Tables:** `gold.fact_sales`
* **Dimension Tables:** `gold.customer_dim`, `gold.product_dim`
  +-------------------+              +------------------+              +------------------+
| gold.customer_dim |              |  gold.fact_sales |              | gold.product_dim |
+-------------------+              +------------------+              +------------------+
| PK customer_key   |<-----1------| fk2 customer_key |              | PK product_key   |
|    ...            |              | fk1 product_key  |----------1->|    ...           |
+-------------------+              |    ...           |              +------------------+
+------------------+

  ---

## 📊 Table Catalog

### 1. `gold.fact_sales`
* **Type:** Fact Table
* **Description:** Stores core transactional sales metrics and key enterprise performance indicators.

| Column Name | Key / Constraint | Data Type | Description |
| :--- | :--- | :--- | :--- |
| `order_number` | — | `VARCHAR` | Unique identifier for the sales order line item. |
| `product_key` | **FK** | `INT` | Foreign key referencing `gold.product_dim.product_key`. |
| `customer_key` | **FK** | `INT` | Foreign key referencing `gold.customer_dim.customer_key`. |
| `order_date` | — | `DATE` | Date when the order was placed. |
| `shipping_date` | — | `DATE` | Date when the order was shipped. |
| `due_date` | — | `DATE` | Date when payment or delivery is due. |
| `sales_amount` | — | `DECIMAL` | Total calculated revenue generated by the item line. |
| `quantity` | — | `INT` | Number of product units purchased. |
| `price` | — | `DECIMAL` | Unit selling price of the product. |

> **💡 Business Logic & Calculations:**
> * `sales_amount` = `quantity` * `price`

### 2. `gold.customer_dim`
* **Type:** Dimension Table
* **Description:** Contains customer demographic details and registration history for customer analysis and segmentation.

| Column Name | Key / Constraint | Data Type | Description |
| :--- | :--- | :--- | :--- |
| `customer_key` | **PK** | `INT` | Primary surrogate key for the customer dimension. |
| `customer_id` | — | `INT` | Natural / source system ID for the customer. |
| `customer_number` | — | `VARCHAR` | Unique business identifier assigned to the customer. |
| `first_name` | — | `VARCHAR` | First name of the customer. |
| `last_name` | — | `VARCHAR` | Last name of the customer. |
| `country` | — | `VARCHAR` | Country of residence. |
| `marital_status` | — | `VARCHAR` | Marital status (e.g., Single, Married). |
| `gender` | — | `VARCHAR` | Gender identity of the customer. |
| `birth_date` | — | `DATE` | Birth date of the customer. |
| `customer_create_date` | — | `DATE` | Timestamp/date when the customer profile was created. |

---

### 3. `gold.product_dim`
* **Type:** Dimension Table
* **Description:** Contains metadata regarding products, hierarchy categorization, and product lifecycles.

| Column Name | Key / Constraint | Data Type | Description |
| :--- | :--- | :--- | :--- |
| `product_key` | **PK** | `INT` | Primary surrogate key for the product dimension. |
| `product_id` | — | `INT` | Natural / source system ID for the product. |
| `product_number` | — | `VARCHAR` | Unique alphanumeric code for the product SKU. |
| `product_name` | — | `VARCHAR` | Descriptive commercial name of the product. |
| `category_id` | — | `INT` | Identifier for the product main category. |
| `category` | — | `VARCHAR` | Name of the primary category (e.g., Bikes, Accessories). |
| `sub_category` | — | `VARCHAR` | Name of the sub-category (e.g., Mountain Bikes, Helmets). |
| `maintanance` | — | `VARCHAR` | Maintenance classification or schedule details. |
| `cost` | — | `DECIMAL` | Standard manufacturing / procurement cost of the product. |
| `product_line` | — | `VARCHAR` | Line of business or product classification segment. |
| `start_date` | — | `DATE` | Effective date when the product was made available. |

## 🔗 Key Relationships

1. **`gold.fact_sales.customer_key`** $\rightarrow$ **`gold.customer_dim.customer_key`** (Many-to-One)
2. **`gold.fact_sales.product_key`** $\rightarrow$ **`gold.product_dim.product_key`** (Many-to-One)
